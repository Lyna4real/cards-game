# 🐾 Purrfect Memory

A fun, interactive memory card game built with **React**, featuring cute dancing cat GIFs! Test your memory by clicking on each unique cat card without repeating any until you win.

## 🔗 Live Demo
Check out the live application here: https://cards-game-2ee4370sp-lyna-s-webdev-projects.vercel.app/

## ✨ Features
- **Dynamic Difficulty Levels:** Choose between Easy (4 cards), Medium (8 cards), and Hard (12 cards).
- **Card Shuffling:** Cards shuffle automatically and smoothly after each correct click.
- **Score Tracking:** Tracks your current score and saves your **Best Score** using `localStorage`.
- **Interactive Modals:** Built-in modal dialogs for game settings, win notifications, and game-over alerts.
- **Responsive Design:** Optimized for both desktop and mobile screens.

## 🛠️ Tech Stack
- **React** (`useState`, `useEffect`, `useRef`)
- **CSS3** (Flexbox, Grid, custom animations)
- **HTML5 Dialog API**

## 🎮 How to Play
1. Select your difficulty level and click **Start Game**.
2. Click on a cat card. The cards will shuffle.
3. Pick a **different** cat card that you haven't clicked yet.
4. If you click the same cat twice, it's game over! 😿
5. Click all cats in your chosen level without repeating to win! 🎉
